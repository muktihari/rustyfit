# fitgen

This is a modified version of [github.com/muktihari/fit's fitgen](https://github.com/muktihari/fit/tree/master/internal/cmd/fitgen), to generate
several `\*.rs` files using Garmin SDK specifications (Profile.xlsx). These generated files enable this library to carry out the decoding and encoding process of FIT files.

I am modifying an existing program written in Go due to my limited bandwidth. The program may or may not be rewritten in Rust; its status is TBD.
